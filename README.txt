**Teamwork:**
We worked collaboratively on both frontend and backend parts of the project. The backend was implemented using Python
Flask and SQLite. The frontend was developed using HTML and CSS along with JavaScript for validations. We mainly worked
incrementally, where one team member implemented a method, feature, improvement, or bug fix. This approach allowed us to
review each other’s code and increase overall control over the application for both of us.
We used a hybrid workflow consisting of both face-to-face and remote working sessions. In the last face-to-face session,
the whole application was discussed, tested, necessary changes were made, and the project was polished together. After
writing or modifying any code, we discussed the changes before finalizing them.
To maintain code consistency and avoid data loss, we used Git for version control. This allowed us to maintain clear
communication, track progress, and collaborate smoothly during development. Using Git for this kind of project was
challenging at first, especially since we preferred incremental development for a relatively large project. We faced
challenges while incrementing our work and avoiding conflicts as much as possible, but this definitely improved our
skills in using Git.
This project also helped us practice Python programming, backend development using Python Flask, frontend development
using HTML and CSS, handling database operations using SQLite, and managing communication between the server and the
application. Most importantly, it helped us learn how to collaborate effectively as a team on larger projects, making
this one of the closest real-world project experiences we have had in this course.
